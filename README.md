# Employee Management System

## Overview
Employee Management System is a console-based application developed using Core Java, JDBC, and MySQL. It helps manage employee records efficiently.

## Technologies Used
- Core Java
- JDBC
- MySQL
- OOPs Concepts
- Exception Handling

## Features
- Admin Login
- Add Employee
- View All Employees
- Search Employee by ID
- Update Employee Details
- Delete Employee
- Department Management
- Salary Management
- Employee Count Dashboard
- Department Wise Employee Count
- Highest Salary Report

## Project Structure

EmployeeManagementSystem
│
├── model
├── dao
├── service
├── util
├── exception
└── main

## Database

Database Name: ems_db

## How To Run

1. Create the MySQL database.
2. Execute the SQL script.
3. Add MySQL Connector JAR.
4. Configure DBConnection.java.
5. Run Main.java.
